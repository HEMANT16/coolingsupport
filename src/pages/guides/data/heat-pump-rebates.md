The transition from fossil-fuel furnaces to electric heat pumps is being heavily subsidized by federal and state governments. The Inflation Reduction Act (IRA) of 2022 allocated billions of dollars to fund tax credits and upfront rebates for energy-efficiency upgrades.

However, because these programs are administered at both the federal and state levels, navigating them is notoriously confusing. Some programs are active today, while others have limited funding or are still in administrative planning.

This guide provides a structured database of the **2026 federal tax credits**, the state-by-state launch status of the **HEEHRA/HEAR rebates**, and guidelines on how to stack incentives to minimize your out-of-pocket costs.

---

## The Three Pillars of IRA HVAC Incentives

Homeowners can qualify for three distinct programs. They are structured differently and have unique income eligibility rules.

### 1. The Federal 25C Tax Credit (Active Nationwide)
*   **Program**: Energy Efficient Home Improvement Credit (Section 25C).
*   **Incentive**: **30% of total installed cost**, capped at a maximum of **$2,000 per year** for qualified air-source heat pumps.
*   **Eligibility**: Available to all taxpayers regardless of income. The installed heat pump must meet the Consortium for Energy Efficiency (CEE) highest performance tier (typically SEER2 $\ge$ 16, EER2 $\ge$ 12, and HSPF2 $\ge$ 9).

### 2. HEEHRA / HEAR Upfront Rebates (State Administered)
*   **Program**: High-Efficiency Electric Home Rebate Act (also known as the Home Electrification and Appliance Rebates - HEAR).
*   **Incentive**: Up to **$8,000** off a heat pump installation at the point of sale.
*   **Income Eligibility Guidelines**:
    *   **Low Income (Under 80% Area Median Income [AMI])**: Covers **100% of costs** up to the $8,000 cap.
    *   **Moderate Income (80% to 150% AMI)**: Covers **50% of costs** up to the $8,000 cap.
    *   **High Income (Over 150% AMI)**: Not eligible for HEEHRA rebates (must rely on 25C tax credits).

### 3. HOMES Program (Whole-Home Energy Savings)
*   **Program**: Home Owner Managing Energy Savings (HEAR Section 50121).
*   **Incentive**: Up to **$4,000** (standard) or **$8,000** (low-income) based on calculated whole-house energy consumption reductions (typically requiring a 20% to 35% modeled energy savings verified by an energy audit).

## How to Stack Your HVAC Rebates

To maximize your savings, you should plan your installation to "stack" federal, state, and utility incentives together. 

### Stacking Example (Moderate-Income Homeowner)

Suppose a moderate-income homeowner in a state with active HEEHRA rebates installs an 18 SEER2 variable-speed heat pump costing **$12,000**:

$$\text{Out-of-Pocket Cost} = \text{Invoice Cost} - \text{HEEHRA Rebate} - \text{Utility Rebate} - \text{25C Tax Credit}$$

1.  **Contractor Invoice**: $12,000
2.  **HEEHRA Rebate (50% of cost, capped at $8,000)**: -$6,000 (Instant discount at point-of-sale).
3.  **Local Utility Rebate**: -$1,000 (Paid via check after installation).
4.  **Net Paid at Purchase**: $5,000
5.  **Federal 25C Tax Credit (30% of net cost, capped at $2,000)**: 30% of $5,000 net cost = -$1,500 (Applied during annual tax filing).
*   **Final Cost of System**: **$3,500** (A total savings of **70.8%**!).

> [!IMPORTANT]
> Always verify that your installer is an **approved trade partner** with your state energy office and local utility. HEEHRA rebates and utility incentives require verification documentation that only certified contractors can submit.

const stateRebateStatus = {
"California": { status: "Waitlisted / Reserved", active: false, desc: "Single-family rebates are fully reserved statewide. New requests are currently placed on a waitlist." },
"New York": { status: "Active", active: true, desc: "HEEHRA rebates are active. You can stack this directly with NYSERDA programs and utility incentives." },

"Florida": { status: "In Planning", active: false, desc: "Florida's program is currently pending final DOE approval. Point-of-sale rebates are not yet active." },
"Colorado": { status: "Active", active: true, desc: "Rebates are fully active and stackable with Colorado's clean energy tax credits." },
"Georgia": { status: "Launching", active: true, desc: "Rebates are active for low-to-moderate-income families statewide." },
"Illinois": { status: "Active", active: true, desc: "Rebates are active. Stacks directly with ComEd and Ameren utility rebates." },
"Michigan": { status: "Active", active: true, desc: "Rebates are active. Instantly deducted by certified EGLE participating contractors." },
"Ohio": { status: "In Planning", active: false, desc: "Ohio's state portal is in the planning phase. Target rollout is mid-to-late 2026." },
"Pennsylvania": { status: "Active / Launching", active: true, desc: "Pennsylvania's rebates are launching. Focus is on energy-efficiency upgrades." },
"North Carolina": { status: "Active", active: true, desc: "Rebates are active. Stackable with Duke Energy and local co-op utility programs." }
};

function initRebateCalculator() {
const stateSelect = document.getElementById('rebate-state-select');
if (!stateSelect) return;

// Populate dropdown
stateSelect.innerHTML = '';
Object.keys(stateRebateStatus).sort().forEach(state => {
const option = document.createElement('option');
option.value = state;
option.textContent = `${state} (${stateRebateStatus[state].status})`;
if (state === 'New York') option.selected = true;
stateSelect.appendChild(option);
});

const incomeSelect = document.getElementById('income-select');
const quoteInput = document.getElementById('install-quote-input');
const calcHeehra = document.getElementById('calc-heehra');
const calc25c = document.getElementById('calc-25c');
const calcUtility = document.getElementById('calc-utility');
const calcNet = document.getElementById('calc-net');
const statusNote = document.getElementById('rebate-status-note');

function calculate() {
const state = stateSelect.value;
const statusData = stateRebateStatus[state] || { active: false, desc: "" };
const income = incomeSelect.value;
const quote = parseFloat(quoteInput.value) || 0;

let heehra = 0;
let utility = 1000; // Flat average estimate for demonstration

if (statusData.active) {
if (income === 'low') {
// 100% of cost, capped at $8,000
heehra = Math.min(quote, 8000);
} else if (income === 'moderate') {
// 50% of cost, capped at $8,000
heehra = Math.min(quote * 0.5, 8000);
}
}

// Remaining cost after upfront rebates
const remainingCost = Math.max(0, quote - heehra - utility);

// 25C tax credit is 30% of remaining net cost, capped at $2,000
const credit25c = Math.min(remainingCost * 0.3, 2000);

const netCost = Math.max(0, remainingCost - credit25c);

calcHeehra.textContent = `$${heehra.toFixed(0)}`;
calc25c.textContent = `$${credit25c.toFixed(0)}`;
calcUtility.textContent = `$${utility.toFixed(0)}`;
calcNet.textContent = `$${netCost.toFixed(0)}`;

let note = `<strong>${state} Status:</strong> ${statusData.desc}<br/>`;
if (!statusData.active) {
note += `<em>Note: Because HEEHRA rebates are not active/available in this state, your HEEHRA savings show as $0. You must rely on the 25C tax credit and local utility rebates.</em>`;
}
statusNote.innerHTML = note;
}

stateSelect.addEventListener('change', calculate);
incomeSelect.addEventListener('change', calculate);
quoteInput.addEventListener('input', calculate);

calculate();
}

if (document.readyState === 'loading') {
document.addEventListener('DOMContentLoaded', initRebateCalculator);
} else {
initRebateCalculator();
}
</script>
